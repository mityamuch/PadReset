# PadReset

Чтение и сброс счётчиков отработанных чернил Epson по USB. Windows 10/11, C# и .NET 10. Работает без активации и интернета.

## Запуск

Нужны драйвер Epson и .NET Desktop Runtime 10. Запустите `PadReset.exe` из папки сборки, подключите принтер и нажмите **Найти принтеры → Подключить**.

Перед сбросом обслужите абсорбер: приложение изменяет только счётчики. После сброса перезапустите принтер и обновите данные. Исходные байты сохраняются в `%LOCALAPPDATA%\PadReset\backups`, записи проверяются чтением.

Каталог содержит 1080 записей: чтение доступно для 675, сброс — для 639. Для части моделей процент рассчитывается только по основным регистрам. Чтение проверено на L3150; полный аппаратный сброс ещё не подтверждён.

## Сборка

Требуется .NET SDK 10. Сторонних пакетов нет.

```powershell
.\build.ps1 -Test
```

Результат: `dist/PadReset/PadReset.exe` и сопутствующие файлы. Для переноса скопируйте всю папку.

## Структура

- `src/PadReset.Core` — профили, протокол D4, EEPROM и сброс.
- `src/PadReset.Windows` — USBPRINT, очередь печати и сеанс принтера.
- `src/PadReset` — WinForms-интерфейс.
- `tests/PadReset.Tests` — проверки протокола, сброса и отказов.

Симулятор доступен во вкладке **Журнал**. Для диагностики есть параметры `--list-usb` и `--check-queues`; они не выполняют сброс.
